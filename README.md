# Stony Cliffs Are Cool — Natural Rock Faces Emerge

Stony Cliffs Are Cool 9minecraft Data Pack is a small worldgen tweak with one job: stop steep ground from looking like a wall of dirt. In vanilla, hills are made of dirt with grass on top, so any sharp drop shows a brown face. This pack turns those exposed faces into stone, the way a real hillside shows the rock beneath once the soil has gone. The rule it applies is narrow on purpose. As land generates, it looks for dirt sitting on a steep, exposed face with stone already nearby, and puts stone there instead.

## What this build is

An unofficial rebuild of **bebebea_loste**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Keeping a pack alive across releases is not a copy-paste job: each Minecraft version bumps the pack format and shuffles texture and model paths, so the tree gets re-mapped and every asset re-checked against the version it is built for. Anything the new release dropped is rebuilt rather than left pointing at a path that no longer exists.
